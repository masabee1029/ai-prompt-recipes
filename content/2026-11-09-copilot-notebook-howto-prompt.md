会議の資料、前回の議事録、Excelの実績表。「全部まとめて読んで答えてくれたら」と思ったことはありませんか。
Copilot Notebookの使い方は、**ノートブックを作って資料を追加し、「この資料だけ」を根拠にCopilotへ質問する**、これだけです。Copilotは、OneDriveやメール、Web全体ではなく、追加した資料だけを使って答えます。
名前は変わり始めていて、**2026年10月後半から「Copilot ワークスペース」という名前に順次切り替わっています**。既存のノートブックは自動でワークスペースになり、中身は残ると案内されています。

**確認日：2026年11月9日**（操作の場所はMicrosoftの公式ヘルプで確認。画面や名前は変わることがあり、会社の管理者の設定で使えない場合もあります）

**この記事でわかること**：Copilot Notebookの作り方と、資料をまとめて質問するコピペ用プロンプト4つ。引き継ぎや案件の資料探しの時間を小さくできます。

## Copilot Notebookの使い方｜作るまでの4手順

公式ヘルプで確かめた流れは次のとおりです。ワークスペースへの切り替えの途中なので、画面の名前が少し違うことがあります。

1. Microsoft Copilotアプリ（m365.cloud.microsoft）を開き、左側の「ノートブック」を選びます。見つからないときは、左上のアプリ起動ツールから「ノートブック」を選びます
2. 「すべてのノートブック」の一覧で「新しいノートブック」を選びます
3. 名前を入れて、「参照にコンテンツを追加」で資料を足します
4. 「作成」を選び、資料について質問します

資料の足し方は、検索、アップロード、OneDrive、URLの貼り付け、ドラッグ アンド ドロップが案内されています。

会社の資料を入れる前に、**会社の決まり（情報の持ち出し・AIの利用規程）を先に確かめる**のが安心です。社外秘や個人情報の扱いは会社ごとに違います。プロンプトの中にも、会社で認められていない情報は書かないようにしましょう。

## 入れられる資料とライセンスの違い

「うちの会社のCopilotで、どこまでできるの？」とよく聞かれるところです。ライセンスで、入れられる資料が変わります。公式ヘルプの表から、仕事でよく使うものを抜き出しました（執筆時点）。

| 資料の種類 | Copilot Chat | Microsoft Copilot（アドオン） |
|---|---|---|
| Word・Excel・PowerPoint・PDF | 使える | 使える |
| OneNote・Loopのページ | 使える | 使える |
| 添付ファイルつきのメールスレッド | 使える | 使える |
| Web等のURL | 使えない | 使える |
| Teamsのチャット、会議の文字起こし・要約 | 使えない | 使える |
| SharePointとOneDrive | 使えない | 使える |
| 1つのノートブックで回答に使われる資料 | 最大50個 | 最初の300個まで |

使うには、Microsoft CopilotまたはCopilot Chatのライセンスが必要で、作成にはSharePointかOneDriveのライセンスも必要と案内されています。個人向けのMicrosoft 365 Personal・Family・Premiumでも利用できると書かれています。

もうひとつ知っておきたいのは、**Excelも資料として読めますが、ノートブックの中でグラフや画像を直接作ることはできない**という点です。あなたの使い方は、「読んで答えてもらう」と「グラフを作ってもらう」のどちらでしょうか。

## そのまま使えるプロンプト｜資料をまとめて質問する

私も最初は、資料を入れただけで「まとめて」と一言で頼み、ぼんやりした答えをもらってつまずきがちでした。よくあるつまずきで、「どの資料を、何のために、どんな形で」を書くと、答えが変わります。

【　】の中を、あなたの仕事に置き換えてください。

**1. 引き継ぎの全体像をつかむ**

> このノートブックの資料だけを使って、【案件名】の引き継ぎメモを作ってください。
> 読む人：【来月から担当する後任者】
> 形式：「いまの状況」「決まっていること」「まだ決まっていないこと」「次にやること（期限つき）」の4つの見出し
> 条件：資料に書かれていないことは足さないでください。分からない所は【不明】と書いてください。

**2. 複数の資料の食い違いを探す**

> このノートブックの【仕様書】と【見積書】と【議事録】を比べてください。
> 納期、数量、仕様について、資料の間で食い違っている所を表にしてください。
> 列は「項目」「資料A」「資料B」「確かめる相手」にしてください。
> 食い違いがなければ「見つかりませんでした」と書いてください。

**3. Excelの実績について質問する**

> 【月次の実績.xlsx】を見て、【不良率】が高かった月を3つ挙げてください。
> それぞれ、同じ時期の【議事録】や【報告書】に原因の手がかりが書かれていれば、資料名と一緒に教えてください。
> 書かれていなければ「資料にはありません」と答えてください。推測で原因を作らないでください。

**4. 会議の前に質問を準備する**

> 明日の【打ち合わせ名】に出席します。このノートブックの資料から、相手に確認しておきたいことを優先順に5つ挙げてください。
> それぞれ、なぜ確認が必要かを1行で書いてください。

「推測で原因を作らないで」の1文があると、もっともらしい作り話が混ざりにくくなります。詳しい防ぎ方は[Copilotのハルシネーションを防ぐプロンプト](copilot-hallucination-prompt.html)にまとめています。会議の文字起こしを資料にしたいときは、[Copilotの録音を文字起こしするやり方](copilot-recording-transcription-prompt.html)が先の一歩です。

## うまくいかないときの直し方

| 困っていること | 考えられる原因 | 直し方 |
|---|---|---|
| 左側に「ノートブック」がない | ワークスペースへの切り替え中、ライセンス、会社の設定 | アプリ起動ツールから探す。だめなら社内の窓口へ |
| 入れたはずの資料が答えに出てこない | SharePointのフォルダーごと追加して、使う資料が絞られた | 確実に使わせたい資料は、ファイルを直接追加する |
| 答えがぼんやりしている | 頼み方が広すぎる | 資料名と出力の形を指定する |
| 古い情報で答えているように見える | 資料が別の場所の別の版になっている | 最新の版が入っているか、ファイル名と場所を確かめる |
| グラフを作ってくれない | ノートブック内ではグラフを直接作れない | 数字の表にしてもらい、Excelでグラフにする |

もし削除で迷ったら、公式ヘルプに「ノートブックの削除は元に戻せない」と書かれている点も覚えておくと安心です。消す前に、中の要約を別の文書に残しておきましょう。

## 向かない人・注意点

Copilot Notebookは「資料が複数あって、行ったり来たりしている人」に向いています。一方で、資料が1つだけなら、WordやExcelのCopilotにそのまま聞くほうが早いことも多いです。社内にCopilotのライセンスがない人は、まず管理者に使える範囲を確かめるのが近道です。

## まとめ

- Copilot Notebookの使い方は、**ノートブックを作り、資料を足して、その資料だけを根拠に質問する**
- 2026年10月後半から**「Copilot ワークスペース」へ名前が順に変わっている**。既存のものは自動で移り、中身は残る
- ライセンスで入れられる資料が変わる。Copilot Chatは最大50個、Microsoft Copilotは最初の300個までが回答に使われる
- プロンプトは「どの資料を・何のために・どんな形で」を書き、「資料にないことは足さない」を添える
- 会社の資料は、利用規程を先に確かめてから入れる
