AIを「質問しやすい先生」として使う

苦手な分野を学ぶときに難しいのは、「どこが分からないのかが分からない」状態になりやすいことです。本や講座は決まった順番で進むため、前提となる知識が抜けていると、そこから先がすべて分からなくなってしまいます。

AIは、こちらの理解度に合わせて説明のレベルを変えたり、同じ内容を別の言い方で説明し直したりできます。「こんなことを聞いたら恥ずかしい」と感じるような基本的な質問も気軽にできるのが利点です。

ただし、AIの説明には誤りが含まれることがあります。特に専門的な内容や最新の情報については、教科書や公式の資料など、信頼できる情報源で確認する習慣をつけておきましょう。

そのまま使える基本の学習プロンプト

まずは、自分の状況を伝えて説明してもらう基本形です。【　】を書き換えて使ってください。

あなたは初心者に教えるのが上手な家庭教師です。私は【学びたい分野：例 統計】が苦手で、これから基礎を学び直したいと思っています。
今の私の理解度：【例：平均は分かるが、標準偏差になると分からなくなる】
学ぶ目的：【例：仕事でデータを読む必要がある】
次のルールで教えてください。
1. 専門用語を使うときは、必ず日常の言葉で説明を添える
2. 一度に説明するのは1つのテーマだけにする
3. 説明のあとに、理解を確かめる簡単な質問を1つ出す
4. 私が間違えたら、どこでつまずいたのかを一緒に考える
まずは、最初に学ぶべきテーマの順番を提案してください。

最初に「学ぶ順番」を提案してもらうことで、全体の見取り図ができます。そのうえで1テーマずつ進めると、つまずいた場所が分かりやすくなります。

理解を深めるための質問のしかた

説明を読んでもピンとこないときは、角度を変えて質問してみましょう。次のような聞き方が役立ちます。

困っていること質問の例
抽象的で分からない「身近なたとえ話で説明してください」
何に使うのか分からない「これが実際に役立つ場面の例を3つ挙げてください」
似た用語と区別できない「AとBの違いを表で比べてください」
前提が分からない「この説明を理解するために先に知っておくべきことは何ですか」
分かった気がするだけ「私の理解が正しいか確かめる問題を出してください」

自分の言葉で説明して確かめる

本当に理解できているかを確かめるには、自分で説明してみるのが効果的です。

【テーマ】について、私の理解を自分の言葉で説明します。間違っている点や足りない点があれば指摘し、正しい説明に直してください。
良い点も一緒に教えてください。
私の説明：【ここに自分の言葉で書く】

人に説明しようとすると、あいまいな部分がはっきりします。AIに指摘してもらえば、自分では気づきにくい思い違いも見つけやすくなります。

学習を続けるための工夫

苦手な分野の学習は、続けることがいちばんの課題です。次のような工夫を取り入れてみてください。

  • 1回の学習は1テーマだけにして、短い時間で区切る
  • 学んだ内容を、最後に3行で要約してもらいノートに残す
  • 次回の最初に「前回の内容の確認クイズ」を出してもらう
  • 分からなかった質問と答えをメモしておき、後で読み返す

学習の計画そのものをAIに相談することもできます。

【分野】の基礎を、【例：1日20分・4週間】で学び直したいです。
今の理解度は【例：用語は聞いたことがある程度】です。
週ごとのテーマと、1日ごとに取り組む内容を表にまとめてください。無理のない分量にし、各週の最後に復習の日を入れてください。

計画どおりに進まなくても、「今週は2日しかできなかったので、計画を組み直してください」と頼めば調整してもらえます。完璧に守ることより、自分のペースで続けられる形に直しながら進めることを大切にしましょう。

会話の内容がいつまで保存されるか、前の会話の内容を次回も覚えているかは、サービスや設定によって異なります（執筆時点）。前回の学習内容は自分でメモしておき、次の会話の最初に貼り付けると確実です。

うまくいかないときの直し方

AIの説明が分かりにくいときは、遠慮せずに条件を変えて頼み直しましょう。

  • 説明が難しい：「中学生に説明するつもりで、もっとやさしく」とレベルを指定する
  • 説明が長すぎる：「3文以内で、いちばん大事なことだけ教えてください」と短くしてもらう
  • 質問攻めで疲れる：「確認の質問はしばらくなしで、説明だけ続けてください」と伝える
  • 答えをすぐ教えてしまう：「答えは言わずに、ヒントを1つずつ出してください」と頼む
  • 内容が正しいか不安：「この説明の根拠になる考え方や、確認できる資料の種類を教えてください」と聞き、教科書などで照らし合わせる

学習の相談で、自分の職場の具体的なデータや他人の個人情報を例として貼り付ける必要はありません。架空の数字や一般的な例に置き換えて質問しましょう。

まとめ

苦手な分野をAIで学ぶときは、自分の理解度と目的を伝え、1テーマずつ質問しながら進めるのがポイントです。

  • 基本のプロンプトで、学ぶ順番の提案と1テーマずつの説明を頼む
  • たとえ話・比較・確認問題など、角度を変えた質問で理解を深める
  • 自分の言葉で説明してチェックしてもらい、重要な内容は信頼できる資料でも確認する

分からないことを何度でも聞ける相手がいると、苦手意識は少しずつ薄れていきます。まずは気になっていた分野のテーマを1つ選んで、試してみてください。
